# Super iCAL Export

## Project Overview

Super iCAL Export is an Obsidian community plugin written in TypeScript and bundled with esbuild.

The plugin exports one or more `.ics` files from Obsidian frontmatter date properties. Each calendar tab has independent settings for date property, output folder, output file name, and update interval.

This project is a fork of https://github.com/obsidianmd/obsidian-sample-plugin. The upstream
was used only for scaffolding (build tooling, CI, repo layout); plugin behaviour is unrelated.

## Commands

```bash
npm install
npm run build
npm run lint
```

Repository: https://github.com/SuperSkypper/super-ical-export

## Release Artifacts

Attach these files to each GitHub release:

- `manifest.json`
- `main.js`
- `styles.css`

The GitHub tag must match the `manifest.json` version exactly, otherwise Obsidian
cannot resolve the plugin. `manifest.json` requires Obsidian 1.4.10 or later
because the plugin uses `AbstractInputSuggest`.

## Important Conventions

- Keep `manifest.json` `id` stable after public release.
- Keep `versions.json` in sync with `manifest.json` version.
- `main.js` is generated by `npm run build`.
- `iCAL-Event-ID` is written to note frontmatter and used as the stable event UID.
- The plugin should remain mobile-compatible, so avoid desktop-only APIs.

## Manual Testing

Copy release artifacts to:

```text
<Vault>/.obsidian/plugins/super-ical-export/
```

Then reload Obsidian and enable **Super iCAL Export**.
